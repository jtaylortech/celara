- RPC-based security scanning (no SSH required)
- 8 security checks (reachability, unlocked accounts, admin API, debug API, mining, peers, sync, chain ID)
- Text, JSON, and markdown report output
- CI/CD integration (exit code 1 on failures)
- Extensible check system
- CLI: scan, report commands
- 21 tests
