# Changelog

Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-03-26

### Added
- Prometheus metrics exporter for EVM nodes
- Multi-chain support (Ethereum, Base, Polygon, Arbitrum)
- Chain-labeled metrics (sync status, block height, peers, gas price)
- Grafana dashboard with 7 panels and chain selector
- CLI: exporter, status, chains commands
- 9 tests
