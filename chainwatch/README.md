# ChainWatch

Observability for decentralized systems.

## Quick Start

```bash
# Start monitoring
chainwatch monitor --validator <address>

# View dashboard
chainwatch dashboard

# Configure alerts
chainwatch alert add --type offline --channel slack

# Check status
chainwatch status
```
