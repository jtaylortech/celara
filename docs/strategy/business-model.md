# Celara Business Model

**Last Updated:** November 4, 2025

## Monetization Framework

**Principle:** Open core → paid reliability → ecosystem compounding.

Celara monetizes where uptime, automation, and compliance matter most.

---

## Revenue Model Flywheel

| Layer | Description | Monetization | Target Customer | Timeline |
|-------|-------------|--------------|-----------------|----------|
| **OSS Adoption** | Free CLIs, templates, exporters | None (brand growth) | Individual devs, validators | Q1 2025 |
| **Managed SaaS** | Hosted dashboards, alerting | Usage-based monthly | Teams running live infra | Q3 2025 |
| **Enterprise Cloud** | Private deployment, SLAs | Annual contracts | Custodians, exchanges, L1s | Q4 2025-Q2 2026 |
| **Advisory** | Integration projects | One-time + retainer | High-touch customers | Continuous |

## Product-Level Monetization

### ChainOps

**Core Value:** Declarative blockchain infrastructure deployments

**OSS Layer:** CDK/Terraform templates, CLI
**Paid Layer:** Managed control plane (auto-updates, state mgmt, backups)

**Pricing:**
- SaaS: $49-$499/mo
- Enterprise: $25K+ annually

**Est. ARPU:** $5K-$25K/year

**Conversion Levers:** Automation, compliance SLAs, managed uptime

---

### ChainWatch

**Core Value:** Node and network observability

**OSS Layer:** Exporters + dashboards
**Paid Layer:** Hosted dashboards, custom alerts, retention

**Pricing:**
- Free tier (public dashboards)
- $10/user/mo (team plans)
- $1,500+/mo (org plans)

**Est. ARPU:** $3K-$15K/year

**Conversion Levers:** Instant alerting, team collaboration, historical data

---

### SecurityKit

**Core Value:** Key management + runtime security

**OSS Layer:** Agent
**Paid Layer:** Vault integrations, policy orchestration, compliance reports

**Pricing:**
- SaaS: $99-$999/mo
- Enterprise: $50K+ annually

**Est. ARPU:** $10K-$40K/year

**Conversion Levers:** Custodian-grade security, audit readiness

---

### ChainETL

**Core Value:** On-chain data ingestion + schema normalization

**OSS Layer:** Connectors
**Paid Layer:** Managed pipelines, data lake hosting, warehouse integrations

**Pricing:**
- Usage-based: $0.10-$0.50/GB processed

**Est. ARPU:** $15K+/year

**Conversion Levers:** Data reliability, analytics flexibility

---

### DAOForm

**Core Value:** Governance + operations automation

**OSS Layer:** Base templates + contract interfaces
**Paid Layer:** Hosted coordination suite (treasury, voting, roles)

**Pricing:**
- Free for <100 users
- $5-$15/user/mo

**Est. ARPU:** $2K-$10K/year

**Conversion Levers:** Community ops, reputation metrics

## Pricing Philosophy

### 1. Start Open, Charge for Confidence

OSS earns credibility; revenue comes from uptime guarantees, security, and automation.

### 2. Align Pricing with Customer Scale

- **Validators:** Per-node pricing
- **DAOs:** Per-member pricing
- **Custodians:** Enterprise SLA pricing

### 3. Composable, Not Bundled

Each module can stand alone or integrate seamlessly — users pay for what they operationalize.

## Customer Ladders

### Solo Validator
**Products:** ChainOps + ChainWatch
**Spend:** Free → $99/mo
**Journey:** Starts OSS → upgrades for uptime alerts

### Staking Provider
**Products:** ChainOps + ChainWatch + SecurityKit
**Spend:** $1K-$5K/mo
**Journey:** Moves to managed nodes + audit dashboard

### Exchange/Custodian
**Products:** Full Suite
**Spend:** $50K-$150K/year
**Journey:** Needs compliance, monitoring, and key mgmt SLAs

### DAO/L1 Foundation
**Products:** DAOForm + ChainETL
**Spend:** $5K-$20K/year
**Journey:** Runs operations + analytics on Celara stack

## The Compounding Effect

**OSS → Distribution:** Lowers CAC via developer evangelism

**SaaS → Retention:** Sticky operational layer (monitoring + control plane)

**Enterprise → Expansion:** High-margin contracts built on OSS trust

**Data → Defensibility:** ChainETL metrics feed ChainWatch insights, creating feedback loops
