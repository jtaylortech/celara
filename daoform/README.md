# DAOForm

Governance-as-Code for DAOs.

## Quick Start

```bash
# Initialize DAO
daoform init --template standard

# Deploy DAO
daoform deploy --chain ethereum

# Create proposal
daoform propose "Proposal title" --description "..."

# Vote on proposal
daoform vote --proposal-id 1 --choice yes

# Check status
daoform status
```
