## [0.1.0] - 2026-03-26

### Added
- Governance engine with proposal lifecycle
- Weighted voting (FOR, AGAINST, ABSTAIN)
- Quorum and threshold resolution
- YAML-based DAO configuration
- YAML file persistence for proposals and votes
- CLI: init, validate, propose commands
- Python SDK (GovernanceEngine, Store)
- 18 tests
