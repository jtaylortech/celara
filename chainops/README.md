# ChainOps

Infrastructure-as-Code for blockchain validators.

## Quick Start

```bash
# Initialize configuration
chainops init ethereum --network mainnet

# Deploy validator
chainops deploy

# Check status
chainops status

# View logs
chainops logs

# Destroy infrastructure
chainops destroy
```
