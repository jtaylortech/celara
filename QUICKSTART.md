# Celara Quickstart Guide

**Welcome to Celara!** This guide will get you up to speed in 5 minutes.

---

## 🎯 What is Celara?

Celara is the **HashiCorp of Web3** — infrastructure tools for blockchain validators, RPCs, and DAOs.

**Five Core Products:**
1. **ChainOps** — Infrastructure-as-Code for validators
2. **ChainWatch** — Observability for decentralized systems
3. **SecurityKit** — Automated security for node operators
4. **ChainETL** — Blockchain data pipelines
5. **DAOForm** — Governance-as-Code

## 💻 Local Development

### Marketing Site

```bash
cd web
npm install
npm run dev
```

Visit http://localhost:3000

### Documentation

All docs are in `docs/` as Markdown files. Edit directly or use your favorite Markdown editor.
